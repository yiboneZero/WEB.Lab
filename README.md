# WEB.Lab — Putter Measure

스마트폰 카메라로 바닥에 놓인 퍼터를 촬영하고, 골프공을 기준 물체로 사용해 퍼터 길이를 계산하는 모바일 웹앱입니다.

- 서비스: https://yibonezero.github.io/WEB.Lab/
- 저장소: https://github.com/yiboneZero/WEB.Lab
- 주요 대상: iPhone Safari, Android Chrome

## 사용 방법

1. 퍼터를 평평한 바닥에 눕힙니다.
2. 일반적인 공인 골프공을 퍼터 중앙 옆에 놓습니다.
3. 스마트폰에서 서비스 주소를 열고 카메라·동작 센서 권한을 허용합니다.
4. `1×` 후면 카메라로 퍼터와 골프공 전체가 보이게 맞춥니다.
5. 좌우와 위아래 기울기를 모두 `±3°` 이내로 유지합니다.
6. 1초 동안 안정된 상태가 유지되면 3초 카운트다운 후 자동 촬영됩니다.
7. 사진에서 골프공의 양 끝과 퍼터의 양 끝을 차례로 지정합니다.
8. 센티미터와 인치로 표시된 결과를 확인합니다.

## 주요 기능

- 모바일 후면 카메라 및 갤러리 사진 입력
- 중력 센서 기반 좌우·위아래 수평 측정
- `±3°`, 1초 안정 유지, 3초 카운트다운 자동 촬영
- 흔들림이나 허용 기울기 초과 시 자동 촬영 취소
- 골프공 지름 `42.67mm` 기준 길이 보정
- 네 개의 측정점 지정, 취소 및 초기화
- cm/inch 동시 결과 표시
- 사진을 서버에 전송하지 않는 브라우저 내부 처리

## 측정 원리

골프공의 이미지상 지름과 퍼터 양 끝의 이미지상 거리를 비교합니다.

```text
퍼터 길이(mm) = 퍼터 픽셀 거리 / 골프공 픽셀 지름 × 42.67
```

`42.67mm(1.680in)`는 USGA와 R&A가 규정한 골프공의 공인 최소 지름입니다. 실제 공의 크기, 카메라 원근, 촬영 각도에 따라 오차가 발생할 수 있으므로 결과는 참고용입니다.

## 실행과 배포

별도 빌드 과정이나 외부 라이브러리가 없는 정적 웹 프로젝트입니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열어 화면을 확인할 수 있습니다. 카메라와 센서는 실제 HTTPS 주소를 연 스마트폰에서 테스트하는 것을 권장합니다. `main` 브랜치의 루트 디렉터리가 GitHub Pages로 배포됩니다.

## 프로젝트 구조

자세한 기준은 [요구사항](docs/requirements.md), 검증 방법은 [테스트 문서](docs/testing.md)를 참고하세요.

## 개인정보

촬영한 이미지는 브라우저 메모리에서만 처리되며 별도의 서버, GitHub 또는 분석 서비스로 전송하지 않습니다. 페이지를 종료하거나 새 측정을 시작하면 기존 작업 데이터는 유지되지 않습니다.

## 현재 제약사항

- 퍼터와 골프공이 동일한 평면에 있다고 가정합니다.
- 골프공은 자동 인식하지 않으며 사용자가 지름의 양 끝을 지정합니다.
- 센서를 지원하지 않거나 권한이 거절된 브라우저에서는 수동 촬영을 사용해야 합니다.
- 공식 클럽 측정 장비를 대체하지 않는 참고용 도구입니다.
