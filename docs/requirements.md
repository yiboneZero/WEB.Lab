# WEB.Lab 요구사항

## 1. 제품 목표

사용자가 별도 측정 장비 없이 스마트폰과 골프공을 이용해 바닥에 놓인 퍼터의 전체 길이를 참고용으로 측정할 수 있어야 합니다.

## 2. 측정 대상과 정의

- 대상: 평평한 바닥에 완전히 눕힌 퍼터
- 시작점: 그립의 가장 바깥쪽 끝
- 종료점: 퍼터 헤드의 가장 먼 끝
- 결과: 두 점 사이의 사진상 직선거리를 실제 길이로 환산
- 단위: 센티미터(cm)와 인치(inch)

## 3. 기준 물체

- 일반적인 공인 골프공 한 개를 사용합니다.
- 계산 기준 지름은 `42.67mm`입니다.
- 골프공은 퍼터 중앙부 옆의 동일한 바닥면에 놓습니다.
- 퍼터와 겹치거나 이미지에서 잘리지 않아야 합니다.
- 바닥과 대비되는 색상의 골프공 사용을 권장합니다.

골프공 규정은 최소 지름이므로 실제 제품이 조금 더 클 수 있습니다. 높은 정확도가 필요하면 사용할 골프공의 실제 지름을 캘리퍼스로 측정해 별도 보정값을 적용해야 합니다.

## 4. 촬영 조건

- 퍼터와 골프공 전체가 한 화면에 들어와야 합니다.
- 딱딱하고 평평한 바닥을 사용합니다.
- 카펫, 경사면, 굴곡이 있는 바닥은 피합니다.
- 후면 `1×` 기본 카메라를 사용합니다.
- `0.5×` 초광각과 디지털 줌은 사용하지 않습니다.
- 휴대폰 카메라가 지면을 향하도록 위에서 촬영합니다.
- 골프공 윤곽을 가리는 그림자와 강한 반사를 피합니다.

## 5. 자동 촬영 조건

- 좌우 기울기: `-3° ~ +3°`
- 위아래 기울기: `-3° ~ +3°`
- 안정 유지 시간: 1초
- 촬영 전 카운트다운: 3초
- 어느 한 축이라도 허용 범위를 벗어나면 카운트다운을 취소합니다.
- 흔들림이 감지되면 안정 상태와 카운트다운을 초기화합니다.
- UI에서 두 축의 현재 각도를 각각 표시합니다.
- 자동 촬영을 사용할 수 없는 경우 수동 촬영을 제공해야 합니다.

## 6. 측정 절차

1. 사진을 촬영하거나 갤러리에서 불러옵니다.
2. 골프공 지름을 가로지르는 양 끝점 두 개를 지정합니다.
3. 그립 끝과 퍼터 헤드의 최외곽점 두 개를 지정합니다.
4. 네 점을 이미지 원본 좌표로 변환합니다.
5. 골프공 픽셀 지름과 퍼터 픽셀 거리를 계산합니다.
6. 골프공 지름 `42.67mm`를 기준으로 실제 길이를 환산합니다.

## 7. 지원 환경

- iPhone: Safari, 최근 주요 iOS 버전
- Android: Chrome, 최근 주요 Android 버전
- 세로 화면 우선, 최소 화면 폭 320px
- HTTPS 환경 필수
- 후면 카메라, 가속도 및 방향 센서 사용
- 권한 요청은 사용자가 누른 `카메라 시작` 동작에서 실행

## 8. 개인정보와 보안

- 촬영 이미지는 브라우저 안에서만 처리합니다.
- 이미지를 외부 서버나 저장소로 업로드하지 않습니다.
- 위치, 연락처 또는 사용자 계정 정보를 수집하지 않습니다.
- HTTPS를 사용합니다.

## 9. 품질 목표

- 권장 촬영 조건에서 반복 측정 편차 목표: `±1.5cm 또는 ±3%`
- 카메라 및 센서 권한 거절 시 이해 가능한 오류 안내 제공
- 320px 이상 화면에서 핵심 버튼과 측정 UI가 잘리지 않을 것
- 잘못 지정한 측정점을 취소하거나 전체 초기화할 수 있을 것

## 10. 범위 제외

- 골프공과 퍼터의 완전 자동 이미지 인식
- 공식 경기 또는 제조 검사 용도의 정밀 측정
- 서버 이미지 저장, 회원 계정 및 측정 기록 동기화
- 여러 높이 또는 경사면의 원근 자동 보정
