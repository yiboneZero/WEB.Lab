# WEB.Lab 모바일 테스트

## 테스트 준비

- 실제 퍼터
- 일반적인 공인 골프공
- 길이 비교용 줄자
- iPhone Safari 또는 Android Chrome
- 평평하고 밝은 바닥

테스트 주소: https://yibonezero.github.io/WEB.Lab/

## 1. 기본 화면

- [ ] 모바일 세로 화면에서 제목과 안내가 잘리지 않는다.
- [ ] 골프공 기준 지름 `42.67mm`가 표시된다.
- [ ] `±1.5°`, 1초 유지 및 자동 촬영 조건이 안내된다.
- [ ] 카메라 시작과 기존 사진 불러오기 버튼이 작동한다.

## 2. 권한과 카메라

- [ ] 카메라 시작 버튼을 누르면 필요한 권한 요청이 나타난다.
- [ ] 권한 허용 후 후면 카메라가 열린다.
- [ ] 권한을 거절하면 오류 안내 후 시작 화면으로 돌아온다.
- [ ] 수동 촬영 버튼이 동작한다.
- [ ] 카메라 닫기 버튼이 카메라 스트림을 종료한다.
- [ ] 기존 사진 불러오기를 누르면 갤러리 또는 파일 선택 화면이 열린다.
- [ ] JPG 사진을 선택하면 측정 화면에 사진이 표시된다.

## 3. 두 축 수평계

- [ ] 휴대폰 왼쪽을 내리면 좌우 각도와 원형 표시가 변한다.
- [ ] 휴대폰 오른쪽을 내리면 반대 방향으로 변한다.
- [ ] 휴대폰 위쪽을 내리면 위아래 각도와 원형 표시가 변한다.
- [ ] 휴대폰 아래쪽을 내리면 반대 방향으로 변한다.
- [ ] 두 축이 각각 `±1.5°` 이내일 때 초록색 상태가 된다.
- [ ] 한 축만 범위 안에 있으면 자동 촬영이 시작되지 않는다.

## 4. 자동 촬영

- [ ] 두 축을 `±1.5°` 이내로 1초간 유지하면 카운트다운이 시작된다.
- [ ] 카운트다운이 3, 2, 1 순서로 표시된다.
- [ ] 카운트다운 중 기울이면 즉시 취소된다.
- [ ] 카운트다운 중 휴대폰을 흔들면 즉시 취소된다.
- [ ] 조건을 계속 유지하면 사진이 한 번만 촬영된다.

## 5. 골프공 자동 탐색

- [ ] 사진을 불러오거나 촬영한 직후에는 골프공이 자동 확정되지 않는다.
- [ ] 골프공을 한 번 터치하면 터치점 중심의 원형 탐색 영역이 표시된다.
- [ ] 해당 원형 영역 안에서 골프공 외곽이 자동 검출된다.
- [ ] 원형 영역 밖은 어둡게 처리되고 내부 사진은 확인할 수 있다.
- [ ] 탐색 영역 경계는 흰 점선 원으로 표시된다.
- [ ] 자동 검출된 골프공 테두리는 초록색 원으로 표시된다.
- [ ] 잔디나 그림자 일부가 포함돼도 피팅 원이 실제 골프공 외곽을 따른다.
- [ ] 크기 슬라이더를 움직이면 초록색 원의 반지름과 백분율이 함께 변경된다.
- [ ] 슬라이더를 이용해 실제 골프공 외곽에 원을 맞출 수 있다.
- [ ] 맞아요를 누르면 검출 지름이 기준값으로 적용된다.
- [ ] 다시 선택을 누르면 다른 위치를 터치할 수 있다.
- [ ] 검출 실패 시 골프공 중심 재선택 또는 재촬영 안내가 표시된다.
- [ ] 골프공 양 끝을 직접 지정하는 수동 기능이 노출되지 않는다.

## 6. 측정

- [ ] 골프공 양 끝의 두 점을 지정할 수 있다.
- [ ] 두 점 지정 후 퍼터 양 끝 지정 안내로 변경된다.
- [ ] 네 점이 사진 위에서 명확히 구분된다.
- [ ] 네 점 지정 후 결과 화면으로 이동한다.
- [ ] 퍼터 두 점을 지정하면 즉시 결과로 이동하지 않고 위치 보정 단계가 표시된다.
- [ ] 주황색 퍼터 끝점 두 개를 각각 누른 채 드래그할 수 있다.
- [ ] 투명 링 중앙에서 퍼터의 실제 끝부분을 확인할 수 있다.
- [ ] 1·2번 배지가 실제 끝점을 가리지 않고 링 바깥에 표시된다.
- [ ] 드래그 중 측정선과 선택점 위치가 실시간으로 갱신된다.
- [ ] 골프공 기준점은 드래그되지 않는다.
- [ ] `이 위치로 측정`을 누른 후에만 결과 화면으로 이동한다.
- [ ] cm와 inch 결과가 동시에 표시된다.
- [ ] 공 검출 지름과 퍼터 선택점 거리가 표시된다.

## 알려진 제약

- 데스크톱 브라우저와 에뮬레이터만으로는 실제 휴대폰 센서를 검증할 수 없습니다.
- 골프공이 퍼터와 다른 위치 또는 높이에 있으면 원근 오차가 커집니다.
- 골프공 규격은 최소 지름이므로 제품별 실제 지름 차이가 결과에 반영될 수 있습니다.
- 본 결과는 공식 측정값이 아닌 참고용입니다.
